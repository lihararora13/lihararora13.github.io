Molly's Yard is housed in converted Victorian stables behind Botanic Avenue, with a courtyard that is one of the city's better warm-evening secrets. The kitchen runs a dedicated vegan menu including a vegan tasting menu, with recent line-ups running artichoke soup, cider-poached pear, butternut squash with pearl barley and vegan ice cream with toffee apple crumble.

Book the tasting menu for the full experience, and ask for the courtyard table if the evening is warm. It is a meat-serving restaurant with a serious vegan programme, so file it as vegan-friendly, and book ahead, because the room is small.
