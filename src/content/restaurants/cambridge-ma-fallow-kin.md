Fallow Kin is a vegetable-forward restaurant in Kendall Square with a seasonal, market-driven menu. It serves meat, but the vegetable dishes are the point of the kitchen, and vegans can build a full meal from them with the server's help.

Order the seasonal vegetable plate and ask the server to build a vegan progression from the current menu, since it changes with the market. Book ahead, since it is the priciest room on this list.
