Quiet Village is a small, calm cafe on Omotecho with vegan-friendly Japanese dishes and drinks, the kind of place that suits a slow lunch between the station and Okayama Castle. The menu is modest and changes with the season, so ask what is vegan on the day.

Order the vegan set if it is running, or the seasonal vegetables with tea. It is inexpensive and unhurried, and it fills a useful gap in the Omotecho cluster when PEACH is booked out.
