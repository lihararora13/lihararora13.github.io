Peace Cafe is a longstanding favourite among vegan and vegetarian travellers, set in a lovely oasis on the river road between two pagodas. The menu is Asian vegetarian cuisine with mainly vegan dishes, and the site holds a fairtrade souvenir shop and community wellness events alongside the restaurant.

Order a Khmer set and a noodle soup, and browse the shop afterwards. It is a vegetarian cafe rather than an all-vegan one, so file it as vegan-friendly, and it is the calmest lunch on this list.
